# 代码运行说明

三份原始 Python 脚本按顺序执行，研究计算逻辑未作修改。为便于在不同电脑上运行，仅将最初的个人电脑绝对路径转换为仓库相对路径。

1. `python 代码/01_main_spx_vix_hurst_empirical.py` — 标普500及VIX-Hurst主实证，输出至 `代码/输出结果/主实证/`。
2. `python 代码/02_strategy_application.py` — 仓位与回测，输出至 `代码/输出结果/策略应用/`。
3. `python 代码/03_gold_oil_extension_optional.py` — GLD/USO、GVZ/OVX扩展，输出至 `代码/输出结果/黄金原油/`。

首次运行：`pip install -r 代码/requirements.txt`。

输入数据位于根目录的 `数据/` 文件夹：`spx.csv`、`GLD.csv`、`USO.csv` 等。原程序依然通过 FRED 在线下载 VIXCLS、GVZCLS、OVXCLS，需联网。运行前应确认数据许可和网络访问。

注意：这些脚本仅完成静态语法检查，尚未验证完整运行和与论文表格的一致性；实验中存在重叠未来收益窗口、未完成样本外验证及回撤术语需区分等问题。
